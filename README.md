# 메이플스토리 보스 파티 체크리스트

## GitHub Pages에 올리는 방법
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치 / `/(root)`를 지정한 뒤 저장합니다.
5. 잠시 기다리면 GitHub Pages 주소가 표시됩니다.

## 기능
- 보스별 파티 목록
- 형 / 나 캐릭터 표시
- 전체 보기, 형 파티 보기, 내 파티 보기, 미완료만 보기 필터
- 파티 완료 체크 및 진행률
- 체크 상태 브라우저 자동 저장(localStorage)
- 모바일 화면 대응

체크 상태는 브라우저에 저장되므로 다른 기기나 브라우저와 동기화되지는 않습니다.
